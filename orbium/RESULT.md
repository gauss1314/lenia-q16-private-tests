# Orbium — first integer hash chain (W1, internal regression only)

PRIVATE. Literature species (Chan 2019). Never publish, never copy into the code
repository (D-062 self-imposed rules 3 and 4).

- Parameters (published in Chan 2019, [verify against the paper]): R=13, T=10,
  mu=0.15 (1500), sigma=0.015 (150), beta=[1]. Not taken from any repository
  data file or program species library.
- Initial state: cultured in the float64 control (`culture_f64.py`, N=128,
  seed 51: random 38x38 patch, amplitude 0.96, 2000 steps). Mass stable to 1%
  over steps 1500–2000, about 208 cells, moving. Cropped 64x64 around the
  maximum, placed in a 256x256 torus, quantised with round-half-even to u16.
  Note: this is NOT CH5 `q16-rne/1` (binary32 bit pattern); acceptable for an
  internal regression vector, revisit when CH5 is implemented.
- Spec: lenia-q16/0.1-draft. Kernel/LUT generated by the implementation
  itself (spec §5, §6), so "full conformance", not the W1 file-distribution
  shortcut.
